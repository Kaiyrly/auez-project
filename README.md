# Qalam — мектептің онлайн кітапханасы

«Қаныш Сәтпаев атындағы Жәнтікей орта мектебі» КММ кітапханасының сайты.
Каталог, жоба презентациясы және «Жоба барысы» фотоальбомы `web` каталогында.

## Сайтты жеке файлмен ашу

[`web/index.html`](web/index.html) файлын жүктеп, браузерде ашыңыз.
Дизайн, JavaScript, мектеп логотипі және 9 жоба фотосуреті осы файлға енгізілген.
[`web/qalam.html`](web/qalam.html) — дәл сол жинақталған нұсқаның екінші атауы.
Мәзірдегі «Басты бет» немесе `qalam.` белгісі негізгі сайтқа,
«Жоба барысы» фотоальбомға апарады.

Нақты аккаунттар мен кітапхана есебі серверде жұмыс істейді. Instagram
жарияланымдары мен қосымша веб-қаріптер интернетті қажет етеді;
интернетсіз жүйелік қаріптер қолданылады.

## Кодты өзгерту және тексеру

Бет құрылымы — `web/index.template.html`. CSS пен JavaScript — `web` ішіндегі
тиісті файлдарда. `index.html` және `qalam.html` құрастыру арқылы жаңартылады.

Node.js 22.13 немесе жаңарақ нұсқада:

```sh
cd web
npm run build:standalone
npm test
npm start
```

Толық нұсқаулық: [web/README.md](web/README.md).
Өзгерістер `feat/project-progress-gallery` тармағында сақталады; деплой жасалған жоқ.
