# Сайтты интернетке жариялау

Нақты аккаунттар Node.js сервері мен SQLite дерекқорын қажет етеді. GitHub Pages сияқты статикалық хостинг аккаунттарды іске қоспайды.

## Docker сервері

Репозиторий түбірінен:

```sh
docker build -t qalam-library .
docker volume create qalam-data
docker run -d --name qalam-library --restart unless-stopped -p 3000:3000 -v qalam-data:/var/lib/qalam qalam-library
docker exec -it qalam-library node create-admin.js
```

Соңғы команда кітапханашының логинін, атын және құпиясөзін терминалда сұрайды. Құпиясөз экранда көрсетілмейді. Өзіңіздің логиніңізді қолданыңыз; тест аккаунттарын пайдаланбаңыз.

Доменді серверге бағыттап, HTTPS reverse proxy орнатыңыз. Сұраудың Host тақырыбы бастапқы доменмен сақталуы керек. Secure cookie әдепкіде қосулы, сондықтан жария сайт HTTPS арқылы ашылуы қажет. Серверге `QALAM_SECURE_COOKIE=0` бермеңіз. SQLite volume сақтық көшірмесін жүйелі жасаңыз; томды жойсаңыз аккаунттар жоғалады.

## Render қолдансаңыз

1. Репозиторийді Render аккаунтыңызға қосыңыз, Docker Web Service жасаңыз. Dockerfile жолы — репозиторий түбіріндегі `Dockerfile`.
2. Тұрақты дискіні `/var/lib/qalam` жолына тіркеңіз. Тұрақты диск тарифі ақы талап етуі мүмкін; тарифті өзіңіз тексеріп таңдаңыз.
3. `QALAM_DATA_DIR=/var/lib/qalam`, `QALAM_SECURE_COOKIE=1` болсын. Бір сервер данасын қолданыңыз.
4. Серверді жариялаған соң хостингтің Shell терминалында `node create-admin.js` орындаңыз.
5. Render берген HTTPS мекенжайын ашыңыз. Әкімші болып кіріп оқушы аккаунттарын жасаңыз.

## Жарияланғаннан кейін тексеру

`/api/session` HTTP 200 қайтаруы керек. Аккаунтсыз кітап каталогы көрінеді. Оқушы аккаунтында админ панель көрінбеуі керек; әкімші API-іне сұрау 403 қайтаруы керек. Оқушы сөредегі кітабын сақтап, шығып, қайта кіргенде сол кітап сақталуы керек. Серверді қайта іске қосқаннан кейін де аккаунт пен сөре сақталуын тексеріңіз.

Бұл файл жариялауды орындамайды. Хостинг аккаунты, рұқсаттар, домен және HTTPS осы ортада конфигурацияланбаған.

## Алғашқы әкімшіні Environment арқылы жасау

Render Shell қолжетімсіз болса, Environment бөліміне `QALAM_INITIAL_ADMIN_LOGIN=librarian` және `QALAM_INITIAL_ADMIN_NAME=Кітапханашы` қосыңыз. `QALAM_INITIAL_ADMIN_PASSWORD` мәніне өзіңіздің 8–128 таңбалы құпиясөзіңізді Render ішінде енгізіңіз. Оны чатқа немесе GitHub-қа жазбаңыз. Save and deploy орындаңыз.

Бұл баптаулар дерекқорда ешбір аккаунт болмаған кезде ғана алғашқы әкімшіні жасайды. Бар аккаунттың құпиясөзін өзгертпейді. Тұрақты дискісіз Free тарифінде дерекқор қайта құрылып, оқушы аккаунттары мен деректері жоғалуы мүмкін. Тұрақты диск қосылғаннан кейін аккаунттың сервер қайта іске қосылғанда сақталуын тексеріңіз.
