# Жоба барысының түпнұсқа фотосуреттері

Пайдаланушы берген `ФОТО.zip` архивіндегі 9 түпнұсқа JPEG фотосурет
осы каталогқа көшірілді. Барлығы 960 × 1280 пиксель; файл мазмұны өзгертілмеген.
Архивте қайталанатын суреттер жоқ.

| Файл атауы | Чаттағы фотосурет |
| --- | --- |
| `library-research.jpg` | Бір оқушы кітап қарап, екіншісі ноутбукпен жұмыс істеп отырған кітапхана |
| `books-and-readers.jpg` | Кітап ұстаған екі оқушы мен жетекші |
| `digital-teamwork.jpg` | Үш адамның ноутбуктермен бірге жұмыс істеуі |
| `library-discussion.jpg` | Кітапханадағы үстелдерді айнала отырған топ, сол жақта сөйлеп тұрған оқушы |
| `classroom-reading.jpg` | Сынып алдында кітап пен қағаздан оқып тұрған екі оқушы |
| `site-demonstration.jpg` | Терезе жанындағы ноутбуктің алдында арқасымен тұрған екі оқушы |
| `reader-feedback.jpg` | Парақ толтырып отырған оқушылармен сөйлесіп тұрған оқушының жақын көрінісі |
| `group-feedback.jpg` | Кітапхананың жалпы көрінісі, алдыңғы ноутбукте Qalam сайты |
| `project-presentation.jpg` | Физика кабинетіндегі экран алдында жобаны таныстыру |

Галереядағы кезек, кезең, тақырып және балама мәтін `project-progress-data.js`
файлында сақталады. Суреттерді жаңартқаннан кейін `web` каталогында
`npm run build:standalone` орындаңыз: ол фотоларды `qalam.html` ішіне де енгізеді.

Пайдаланушы әзірге тек GitHub-та өзгертуге рұқсат берді. Деплой жасамаңыз,
қолданыстағы `qalam-library-site` тармағына біріктірмеңіз.
